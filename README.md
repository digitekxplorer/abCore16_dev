# abCore16_dev

The abCore16 project is an in-depth educational software suite designed to provide a practical and comprehensive
understanding of the entire lifecycle of software execution on a custom-designed 16-bit microprocessor. It 
encompasses a complete toolchain, including a low-level programming language (Simple Source Language - SSL), 
an SSL compiler, a Simple Assembly Language (SAL) assembler, a machine code disassembler, and a detailed 
microprocessor simulator. This project allows users to write programs using 16-bit data and addressing 
capabilities, see them translated through various stages of abstraction, and ultimately observe their execution 
on a simulated 16-bit CPU architecture. The primary goal is to demystify computer architecture, 16-bit instruction 
set design, language translation processes (compilation and assembly), and the fundamental principles of CPU 
operation. Conceptual SystemVerilog code is also provided as a blueprint for potential hardware implementation 
of the 16-bit abCore16 on an FPGA.

Project Development Process: abCore16 with Google AI Studio (Gemini 2.5 Pro)
The development of the abCore16 microprocessor toolchain and simulator was an iterative and collaborative process, 
leveraging the capabilities of Google AI Studio and the Gemini 2.5 Pro model. The process can be characterized by 
a series of prompts, code generation, testing, feedback, and refinement cycles.
